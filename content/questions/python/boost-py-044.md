## 문제

What are the built-in types of python?

## 해설

Python의 Built-in type은 아래와 같다.

- Integer
- Floating-point
- Complex number
- String
- Boolean
- Built-in function

자세한 내용은 [Built-in Types - Python documentation](https://docs.python.org/3/library/stdtypes.html) 참고!
