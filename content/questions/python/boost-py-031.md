## 문제

How to comment multiple lines in python?

## 해설

`#`을 여러 줄 사용하여 여러 줄의 주석을 달 수 있다.

```python
# this is my comment
# I am commenting multiple lines
# - boostcamp ai tech team 4
```

따옴표를 이용한 주석은 Docstring 형식으로 자세한 내용은 [#32](#32)를 참고!
